豆泥日历 1.0.1 / DouNi Calendar

- Windows 改为安装向导：选择安装目录，按需勾选“开机启动”。
- 自启由安装脚本创建 Windows 启动文件夹快捷方式，程序菜单与安装设置同步。
- 升级请选择原目录；更新和卸载保留个人 `data`。

本次只更新 Windows，提供一个 `Windows-x64-Setup.exe` 安装包。个人记事和设置不包含在发行包内。

Mac 版继续使用 [v1.0.0 的通用版](https://github.com/HerronWonder/DouNi-Calendar/releases/tag/v1.0.0)，支持 Apple 芯片和 Intel。
