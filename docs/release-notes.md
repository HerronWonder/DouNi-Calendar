豆泥日历 / DouNi Calendar

- Windows：下载 `Windows-x64.zip`，解压后运行 `DouNiCalendar.exe`。
- macOS：下载 `macOS-universal.zip`，解压后运行 `DouNi Calendar.app`，支持 Apple 芯片和 Intel Mac，最低 macOS 13。
- 默认透明和鼠标穿透，支持格内记事、月份切换、手绘风格、记事字号和常见节日。
- 点击日历外部自动保存并退出编辑。

每个平台只提供一个完整使用包，不另行重复上传可执行文件或源码压缩包。个人记事和设置不包含在发行包内。更新时退出旧版本，保留程序旁的 `data` 文件夹。

macOS 包为本地签名构建，尚未配置 Apple Developer ID 签名和公证。
