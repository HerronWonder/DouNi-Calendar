豆泥日历 / DouNi Calendar

运行 Setup.exe 安装包，选择安装目录，按需勾选“开机启动”。
适用于 Windows 10 / 11（64 位），默认安装到当前用户的可写目录。
安装后从开始菜单打开豆泥日历，也可以直接运行安装目录中的 DouNiCalendar.exe。

托盘
  左键：进入编辑模式；再点一次保存并完成。
  右键：打开菜单。
  图标在编辑模式下会变色。找不到图标时，展开右下角“^”。

使用
  默认透明，鼠标点击仍作用于桌面。
  点击日期格透明输入记事，Enter 保存，Shift+Enter 换行。
  点击右上角“完成”或日历外部，保存并退出编辑。
  “编辑模式”启用年月导航和日期格记事。
  左右箭头切换月份；点击年份或月份可直接输入。
  年月输入后按 Enter 或“完成”保存；非法输入会还原。
  闹钟图标回到今天，并恢复自动换月；旁边显示今天的星期。
  “移动与缩放”开启后，拖动日历可移动，拖动边缘或右下角可缩放。
  “手绘风格”和“显示节假日”可分别勾选。
  “字体大小”输入 8—32 的数字，Enter 确认，只调整记事文字。
  “开机启动”与安装时的选择一致，可随时开启或关闭。
  勾选后会在当前用户的 Windows 启动文件夹创建 DouNi Calendar 快捷方式。

数据
  data/settings.ini         显示位置、大小、月份与样式
  data/notes/年-月/日.txt    每日记事，UTF-8 文本
  data/backup/年-月/日.txt   对应记事最近一次覆盖前的版本

更新时选择原安装目录，记事和设置会保留。卸载也会保留 data。
从旧版迁移到新目录时，先退出旧日历，再把旧目录中的 data 复制到新安装目录。

迁移前退出程序，复制整个“豆泥日历”文件夹，带上 data。
放到具有写入权限的目录。迁移后如需开机启动，请在新位置重新勾选。
从备份恢复时先退出，将 backup 中对应文件复制到 notes 的同名位置。
程序完全本地运行。仅标节日名称，不含调休；农历节日支持 1901—2100 年。
