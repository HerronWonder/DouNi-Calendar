豆泥日历 / DouNi Calendar

适用于 macOS 13 或更新版本，支持 Apple 芯片和 Intel Mac。
解压后，先通过 Finder 将整个文件夹移到“文稿”等具有写入权限的位置，再打开“DouNi Calendar.app”。
应用需要在旁边建立 data 文件夹来保存记事。

菜单栏
  左键图标：进入编辑模式；再点一次保存并完成。
  右键图标：打开菜单。

使用
  默认透明，鼠标操作桌面和下面的窗口。
  点击日期格直接输入，Enter 保存，Shift+Enter 换行。
  点击“完成”保存并恢复穿透。
  左右箭头切换月份；点击年份或月份可输入数字。
  闹钟图标回到今天，恢复自动换月；旁边显示今天的星期。
  “移动与缩放”开启后可拖动日历和调整边缘。
  “字体大小”输入 8—32，Enter 确认，仅调整记事文字。
  “手绘风格”“显示节假日”和“登录启动”可按需启用。
  非法输入会还原，不弹出提示窗口。

数据
  data 文件夹保存在 .app 的同级目录，不保存在应用包内部。
  data/notes/年-月/日.txt 为 UTF-8 记事。
  data/backup/年-月/日.txt 为最近一次覆盖前的版本。
  更新时退出应用并替换 .app，保留原有 data。
  迁移时退出应用，复制 .app 和同级 data 文件夹。

Mac 构建由原生 AppKit 实现，无需安装额外运行时。
未配置 Apple Developer ID 的发行包只有本地签名，没有 Apple 公证；macOS 可能要求按系统流程确认开发者来源。
程序仅本地保存。节日名称不代表放假或调休安排。
