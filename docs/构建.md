# 从源码构建

Windows 使用 Zig 0.15.2 和 Inno Setup 6.7 或更新版本：

```powershell
./tools/build.ps1
./tools/build-installer.ps1 -Version 1.0.1 -IsccPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

安装包输出到 `release`。`tools/windows-installer.iss` 定义目录选择、开机启动快捷方式、开始菜单和卸载；只包含程序和使用说明，更新和卸载保留个人 `data`。

macOS 使用 Xcode Command Line Tools：

```sh
DOUNI_VERSION=1.0.0 bash src/macos/build.sh "$PWD/dist/DouNi-Calendar-macOS"
```

安装向导中文翻译来自 [Inno Setup is-6_7_4](https://github.com/jrsoftware/issrc/blob/is-6_7_4/Files/Languages/Unofficial/ChineseSimplified.isl)，原维护者信息保留在文件头。
